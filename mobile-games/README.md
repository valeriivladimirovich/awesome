# Карманная аркада

Сайт с короткими играми для телефона. Один файл `index.html`, без сборки и зависимостей.

Игры:

- **Змейка** — свайпы или стрелки, змейка ускоряется с каждым солнышком.
- **Пары** — найди 8 пар карточек за минимум ходов.
- **Три в ряд** — крестики-нолики против компьютера (лёгкий и сложный уровни).
- **Реакция** — замер скорости реакции в миллисекундах.
- **Цифры** — нажми числа от 1 до 25 по порядку на время.

Рекорды хранятся в `localStorage` на устройстве игрока.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages для репозитория
и перейдите на `/mobile-games/`.
